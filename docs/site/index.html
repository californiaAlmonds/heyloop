01 / A quieter way to work

Step away.
Not out of the conversation.

Long-running coding agents shouldn't keep you at your desk. HeyLoop is building a private connection between the work on your computer and the phone in your pocket.

01

Know what's happening.

Agents send status updates through MCP. Your local daemon keeps the conversation and history together.

02

Have the final say.

HeyLoop approval requests wait for your answer. The first answer wins; unanswered requests default to deny.

03

Keep it yours.

Your computer owns the history. Your self-hosted relay passes ciphertext. No account or hosted dashboard required.

Terminal / quick start
git clone https://github.com/californiaAlmonds/heyloop.git
cd heyloop
npm install
npm run cli -w @heyloop/daemon -- start

In a second terminal, configure your coding workspace:

npm run cli -w @heyloop/daemon -- setup vscode /path/to/project

A few things to know.

What can I use today?

The local MCP daemon, desktop approvals, CLI messaging, encrypted pairing protocol, and local relay have working smoke tests. The Expo Android app is scaffolded; phone screens, push notifications, and desktop-first routing are still on the roadmap.

Can it answer VS Code's built-in Allow prompts?

No. HeyLoop handles its own MCP approval requests, not VS Code's native tool confirmations. Use a narrow command allowlist for trusted operations. Never enable global auto-approve to work around this limitation.

Do I need an account?

No HeyLoop account. Pairing uses a QR code to exchange a secret between your devices. You control the relay deployment; deploying to Cloudflare requires your own Cloudflare account.

Where does my data live?

Conversation history lives in SQLite on your computer. The relay queues encrypted messages until they are acknowledged. Treat pairing QR codes and daemon tokens like passwords.
